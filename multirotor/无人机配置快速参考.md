## 🔧 常见操作

### 1. 添加新无人机

编辑 `drones_config.json`:
```json
{
  "drones": {
    "UAV4": {
      "enabled": true,
      "type": "virtual",
      "isCrazyflieMirror": false
    }
  }
}
```

**字段说明**:
- `enabled`: `true` = 启用，`false` = 禁用
- `type`: `"virtual"` = 虚拟无人机(AirSim)，`"physical"` = 实体无人机(Crazyflie)
- `isCrazyflieMirror`: 是否为 Crazyflie 镜像（虚实协同）

---

### 2. 配置实体无人机（Crazyflie）

```json
{
  "drones": {
    "CF1": {
      "enabled": true,
      "type": "physical",
      "isCrazyflieMirror": true
    }
  }
}
```

⚠️ **注意**: `type` 和 `isCrazyflieMirror` 必须匹配：
- 实体无人机: `type: "physical"` + `isCrazyflieMirror: true`
- 虚拟无人机: `type: "virtual"` + `isCrazyflieMirror: false`

---

### 3. 禁用/启用无人机

```json
{
  "drones": {
    "UAV2": {
      "enabled": false,  // 设为 false 禁用
      ...
    }
  }
}
```

💡 **提示**: 禁用的无人机不会出现在训练列表中。

---

### 4. 配置 DQN 训练使用的无人机

#### 方式 A: 使用所有启用的无人机
```json
{
  "training": {
    "dqn": {
      "use_all_drones": true
    }
  }
}
```

#### 方式 B: 指定特定无人机
```json
{
  "training": {
    "dqn": {
      "use_all_drones": false,
      "drone_list": ["UAV1", "UAV3"]
    }
  }
}
```

⚠️ **DQN 限制**: 当前 DQN 仅支持单无人机训练，会使用列表中的第一个。

---

### 5. 配置 DDPG 训练使用的无人机

```json
{
  "training": {
    "ddpg": {
      "use_all_drones": true
      // 或
      // "use_all_drones": false,
      // "drone_list": ["UAV1", "UAV2", "UAV3"]
    }
  }
}
```

✅ **DDPG 支持**: DDPG 支持多无人机协同训练。

## 💻 代码使用示例

### 基本用法

```python
from Algorithm.drones_config import DronesConfig

# 1. 加载配置
config = DronesConfig()

# 2. 获取所有无人机
all_drones = config.get_all_drones()
# 输出: ['UAV1', 'UAV2', 'UAV3']

# 3. 获取启用的无人机
enabled = config.get_enabled_drones()
# 输出: ['UAV1', 'UAV3'] (假设UAV2被禁用)

# 4. 获取 DQN 训练无人机
dqn_drones = config.get_training_drones('dqn')
# 输出: ['UAV1']

# 5. 获取 DDPG 训练无人机
ddpg_drones = config.get_training_drones('ddpg')
# 输出: ['UAV1', 'UAV2', 'UAV3']
```

---

### 检查无人机信息

```python
# 检查无人机类型
drone_type = config.get_drone_type('UAV1')
# 返回: 'virtual' 或 'physical'

# 判断是否为实体无人机
is_physical = config.is_crazyflie_mirror('UAV1')
# 返回: True 或 False

# 判断是否启用
is_enabled = config.is_enabled('UAV1')
# 返回: True 或 False

# 获取完整信息
drone_info = config.get_drone_info('UAV1')
# 返回: {'enabled': True, 'type': 'virtual', ...}
```

---

### 在训练脚本中使用

```python
import sys
from Algorithm.drones_config import DronesConfig

# 加载配置
drones_config = DronesConfig()

# 获取训练无人机
drone_names = drones_config.get_training_drones('dqn')

# 验证
if not drone_names:
    print("❌ 错误: 没有可用的训练无人机")
    sys.exit(1)

# 显示信息
print(f"✅ 训练无人机: {drone_names}")
for drone in drone_names:
    drone_type = "实体" if drones_config.is_crazyflie_mirror(drone) else "虚拟"
    print(f"   - {drone}: {drone_type}无人机")

# 使用第一个无人机（DQN单智能体）
training_drone = drone_names[0]
```

## 📋 API 快速参考

### 获取无人机列表
| 方法 | 返回值 | 说明 |
|------|--------|------|
| `get_all_drones()` | `List[str]` | 所有无人机名称 |
| `get_enabled_drones()` | `List[str]` | 启用的无人机名称 |
| `get_training_drones('dqn'\|'ddpg')` | `List[str]` | 训练使用的无人机 |

### 获取无人机信息
| 方法 | 返回值 | 说明 |
|------|--------|------|
| `get_drone_info(name)` | `Dict` | 无人机详细信息 |
| `get_drone_type(name)` | `str` | `'virtual'` 或 `'physical'` |
| `is_crazyflie_mirror(name)` | `bool` | 是否为实体无人机 |
| `is_enabled(name)` | `bool` | 是否启用 |

### 保存配置
| 方法 | 说明 |
|------|------|
| `save_config()` | 保存修改后的配置 |

## ⚠️ 常见问题

### Q1: 修改配置后不生效？
**A**: 重启训练脚本，确保重新加载配置文件。

### Q2: 提示"没有可用的训练无人机"？
**A**: 检查以下几点：
1. 无人机是否已启用 (`enabled: true`)
2. `drone_list` 中的名称是否正确
3. 无人机名称拼写是否一致

### Q3: DQN 如何使用多个无人机？
**A**: 现在 DQN 已支持多机训练！只需在 `drones_config.json` 中配置多个无人机：
```json
{
  "training": {
    "dqn": {
      "use_all_drones": true  // 或指定多个无人机
    }
  }
}
```
多机模式下，所有无人机共享同一个 DQN 模型，轮流执行动作。

### Q4: DDPG 可以混合虚拟和实体无人机吗？
**A**: 可以！配置好 `isCrazyflieMirror` 字段即可实现虚实混合。

### Q5: 如何临时禁用某个无人机？
**A**: 将该无人机的 `enabled` 设为 `false`，无需删除配置。

## 💡 提示与技巧

### 1. 使用版本控制
建议将 `drones_config.json` 加入版本控制，方便团队协作和配置回溯。

### 2. 备份配置
修改配置前，先备份一份：
```bash
cp drones_config.json drones_config.json.bak
```

### 3. JSON 格式验证
使用在线工具验证 JSON 格式：https://jsonlint.com/

### 4. 配置注释
当前主配置已经精简为“机器可读优先”格式，不建议再往 JSON 中加入 `description` 一类说明字段。把解释写到 Markdown 文档里更稳妥。

### 5. 环境隔离
为不同环境（开发/测试/生产）维护不同的配置文件：
- `drones_config_dev.json`
- `drones_config_test.json`
- `drones_config_prod.json`

## ✅ 最佳实践

1. ✅ 所有无人机配置集中在 `drones_config.json` 中管理
2. ✅ 使用 `DronesConfig` 类而不是直接读取 JSON
3. ✅ 训练前验证无人机列表非空
4. ✅ 只保留运行时真正会读取的字段
5. ✅ 定期检查禁用的无人机，清理过期配置
